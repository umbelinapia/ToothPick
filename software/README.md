# Software

Host-side code, runs on a laptop, not on a microcontroller.

[`vision-pick-and-place/`](vision-pick-and-place): pulls a frame from the
camera firmware, detects the target disc with OpenCV, and drives the arm
firmware over serial through the full pick/flip/drop cycle. See
[`vision-pick-and-place/README.md`](vision-pick-and-place/README.md) for the
final version vs. iteration history.
