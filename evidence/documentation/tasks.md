# Tasks

The coursework brief (CW2, 25WSC912) set the task as: design, build, and test
a system to locate the disc, flip it upside down, and pick and place it into
a fixed destination — with sensors used to locate the disc even where its
position might otherwise be predictable, since the flip can leave it
uncertain.

Broken down for the team:

- Locate the disc using vision, not fixed coordinates
- Flip the disc upside down ("heads" to "tails")
- Pick the disc up and place it at a fixed destination
- Run repeatable experiments picking the disc from random starting positions,
  confirming the system works from an unknown start, not just a rehearsed one

Who worked on which part of the build is tracked in
[`gantt-chart.md`](gantt-chart.md).
