# CAD

STL exports of the team's own designed/printed parts, grouped by subsystem.

- `base-and-drivetrain/` — base plate, mounting bracket, base gear, gear links
- `gripper-and-links/` — gripper, flipper, link, motor connectors
- `camera-mount/` — camera housing, mount, attachment point

Native CAD source files (SolidWorks `.sldprt`/`.sldasm`, Inventor `.prt`/`.iam`)
are kept with the original project files rather than duplicated in this
repo — they're large, proprietary formats that need the original CAD
software to open, whereas the STL meshes here can be viewed in any STL
viewer or 3D-printing slicer.

Third-party STEP files used only as dimensional reference during design
(vendor robot-arm geometry) are not included — they aren't this team's own
work.
